# SubtitlePop MCP 使用说明

这是独立开源的字幕文本工具，使用本地 stdio 协议。无需 SubtitlePop 账号、API key 或付费额度。它不包含商业网站源码，也不会调用转写、翻译或视频渲染服务。

## 从源码运行

需要 Node.js 22 或更高版本。

```sh
git clone https://github.com/j-river/subtitlepop-mcp.git
cd subtitlepop-mcp
npm ci --ignore-scripts
npm run check
npm run smoke
```

在支持本地 MCP 的客户端中添加服务：命令为 `node`，参数为你本机此项目 `src/cli.js` 的绝对路径。不同客户端的配置文件位置和格式可能不同；README 提供常见配置结构。

发布到 npm 后，也可以使用 `npx -y subtitlepop-mcp@0.1.0`。仓库存在或 `server.json` 已准备不表示 npm/MCP Registry 发布已经完成，以实际可访问的发布页面为准。

## 可以这样问 AI

“检查下面的 SRT，列出重叠和阅读速度问题，不要自动删除任何字幕。”

“把字幕整体延后 1500 毫秒，再返回 VTT 格式。保留原始文件，不覆盖。”

“提取可读正文，告诉我会丢失哪些格式信息。”

字幕文本通过工具参数传入。读取文件和保存结果由客户端自己的文件工具完成，需要客户端已有权限；此服务不读取路径、不下载 URL、不写文件。

## 必须知道的边界

- 每次最多 64 KiB UTF-8、1000 条字幕。
- 检查结果分页返回，按照 `nextOffset` 获取下一页。
- 正偏移表示更晚，负偏移表示更早；整体偏移不会解决重叠或逐渐累积的不同步。
- 默认拒绝负时间，明确选择 `clip` 才裁剪；结果会列出缩短和删除的原始索引。
- 输出默认纯文本，可能丢失样式、定位、说话人标记、逐词时间和部分元数据。
- 阅读速度、每行长度和行数是可调整的经验阈值，不是无障碍或平台标准认证。
- 本地服务不联网，不代表整个 AI 客户端离线。字幕可能由客户端发送给模型服务商，应按客户端实际隐私设置判断。

需要从音视频生成字幕、调整视觉样式或导出带字幕的视频，可以使用独立的 [SubtitlePop](https://subtitlepop.com/)。MCP 免费文本工具不会自动产生商业网站消费。
